# One feed call per stop or service per window, across every data centre

NUS's shuttle feed is undocumented and not ours, so terminus must not add load to it. A per-data-centre cache alone let traffic spread over many Cloudflare data centres multiply the calls. So a cache miss asks a feed gate first: one Durable Object per stop or service, which lets one call through per window everywhere (1c2c9047). LTA DataMall goes through the same path. If the gate can't be reached, it is skipped and the data centre's own limits apply, so an outage of the gate never takes answers down with it. Refusals, 429s, 5xxs and timeouts open a breaker rather than being retried.
