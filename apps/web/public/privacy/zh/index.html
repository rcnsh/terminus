terminus 是一个免费、独立的学生项目。它只保留告诉你该搭哪班巴士所需的信息，你随时可以自己删除所有信息。

保存什么

  • 你的邮箱地址（如果你提供了），用于发送登录验证码和链接，并在你的账户添加或移除设备时通知你。绝不保存任何密码。
  • 你的课表：每节课的星期、时间、地点和最近的巴士站，以及你导入的 NUSMods 分享链接。
  • 你的设置：家附近的车站（只有车站名称，绝不保存你的地址或坐标）、你走到那里需要的分钟数、你的步速、收藏、空档和一天时段的偏好、你的语言，以及你看过哪些一次性设置页面。
  • 巴士有多挤（总体统计）：当一班巴士快到有人查询的车站时，terminus 会在一个计数上加一，记录这条线路在那个车站有多常很挤，按日子类型和每半小时划分。这个计数和你或你的请求没有任何关联；巴士的车牌号只保留两天，以免同一班车被重复计算。
  • 今天的行程：今天的行程是哪班巴士，以及发生了什么：你不去了，或者在应用能从你的位置判断时，你已上车、错过了，或已到达。terminus 从不询问。它保留到当天结束，让你的其他设备显示同样的信息，然后在午夜删除；如果你删除账户，则立即删除。当应用随行程发送你的位置时，只保留判断结果（在车站、在车上、错过了或已到达），绝不保留位置本身。如果你在 Android 应用中开启“上车时自动识别”，它只会在行程中、从出发时间到你到达为止、行程通知显示期间，大约每 20 秒发送一次你的位置。当它识别到你在车上时，会在乘车期间保留巴士的车牌号，以便从 NUS 的数据中读取它到达你那一站的时间。
  • 每次行程的情况：保留 35 天，每节课每天的行程只记一个词：在车上、错过了、不去了或已到达。绝不记录时间、车站或位置。它用来建议你为经常错过的课提早一班出发，或停止提醒你经常不去的课。你在那里做的选择会一直保留，直到你修改。
  • 你发送的报告：当你告诉 terminus 某个答案不对时，你的说明和你当时看到的答案会和你的账户一起保存，用来和巴士的实际情况对照。报告也会连同你的邮箱地址发给运营 terminus 的人，方便回复你。
  • 你的设备：每台已配对设备报告的名称（例如“Google Pixel 8”）、它运行的应用和版本、添加时间和最后使用时间；对于接收通知的设备，还有它的推送地址：Android 应用的 Firebase 地址，或网页应用中你的浏览器推送服务（Apple、Google 或 Mozilla）给它的地址以及用于加密的密钥。登录和设备令牌只以单向哈希的形式保存。

不用邮箱使用应用

Android 和 Mac 应用不需要邮箱地址也能使用。第一次打开时，应用会创建一个没有邮箱的账户，只有那台设备知道，并为它保存和上面相同的内容：你的课表、设置、设备名称和最后使用时间。除非你之后添加邮箱，否则没有任何东西能识别你；添加邮箱可以保留你的设置，并让你在其他设备上登录。

没有邮箱的账户会在应用最后一次使用它的 60 天后被删除，连同里面的所有内容。你也可以在应用的设置里立即删除它。卸载应用不会删除账户，只是不再使用它。

当你从应用登录时，terminus 会保留一个短暂的请求（你的邮箱地址、设备名称和请求时间），直到你在邮件中批准，最多 15 分钟。

不保存什么

  • 你的位置。当应用发送你的位置来找最近的车站时，位置会被取整到约 11 米，只用于那一次答案，不会保存。同一个答案也会检查你是否在你家附近车站所服务的校内宿舍里，以免你已经在那里时还叫你回家；具体是哪个宿舍从不保存。位置放在请求的地址里，而 terminus 自己的请求日志是关闭的；传送每个请求的 Cloudflare 只为送达而处理它。
  • 没有跟踪、广告、分析 Cookie 或追踪器。唯一的 Cookie 是让你保持登录的那一个。

为了改进估计，terminus 会记录关于答案的匿名统计：哪个车站、哪条线路和哪班车（车牌号），以及多久后到达。这些不包含账户、邮箱或位置。

当应用识别到一次完整的乘车（巴士开出并到达你那一站）时，会保留这段路程用了多长时间：线路、两个车站、巴士车牌、小时和日期，保留 120 天，用来了解巴士在车站之间实际要多久。它不包含账户、设备或位置，也没有任何东西把它和你联系起来。

如果你要求不再收到邮件，那个地址会被加入屏蔽名单，从此不会再向它发送登录邮件。屏蔽名单不与账户关联，删除账户后仍会保留，因为这正是它的用途。

谁处理这些信息

所有内容都运行在 Cloudflare 上（托管、数据库、邮件发送），数据中心可能在新加坡以外。巴士时间来自 NUS 的校园巴士数据；NUS 不会收到任何关于你的信息。你的数据绝不出售或分享。

有些页面会从其他服务加载内容，它们会像你访问的任何网站一样看到你的 IP 地址：

  • Cloudflare Turnstile：在登录表单上，用来确认你是真人。
  • Google Fonts：本网站使用的字体。
  • cdnjs（Cloudflare）：账户页面上的二维码库。
  • unpkg：仅用于 API 文档页面。

在装有 Google Play 服务的 Android 手机上，terminus 使用 Firebase Cloud Messaging（Google）通知应用你的行程有变化，这样应用就不必一直查询。消息只说明这一点，以及行程处于哪个阶段（例如“该出发了”）；然后应用会自己向 terminus 询问详情。

如果你在网页应用中开启通知，同样的消息会经过你的浏览器自己的推送服务（Safari 用 Apple 的，Chrome 用 Google 的，Firefox 用 Mozilla 的），并经过加密，只有你的浏览器能读取。然后你的浏览器会向 terminus 询问详情并显示通知。在网页应用中关闭通知或在那里退出登录，会删除这个地址。

当你导入课表时，terminus 会向 NUSMods 查询你链接中各模块的课表。它只发送模块代码，不发送任何关于你的信息。

步行时间按照 OpenStreetMap 的步行道路计算（地图数据 © OpenStreetMap 贡献者），教室位置来自 NUSMods。两者都只下载过一次用来计算距离；任何关于你的信息都不会发送给它们。

保留多久

  • 直到你删除账户，删除会立即移除所有内容。
  • 登录链接和请求 15 分钟后失效，浏览器会话 30 天后失效，已配对的设备 90 天不使用后失效。
  • 没有邮箱的账户在最后一次使用 60 天后删除。
  • 每次行程的情况保留 35 天；今天的行程在午夜删除。清除行程记录（在应用的设置里，或在账户页面）可以更早删除它，而不影响账户的其他部分。

你可以做什么

在账户页面上，你可以查看和编辑上面的所有内容、把它们全部下载为文件、在所有设备上退出登录，或删除你的账户。应用也可以查看和移除你的设备。没有邮箱的账户由它的应用管理，应用可以导出或删除它。

联系方式

关于你的数据在新加坡《个人数据保护法》下的问题或请求：privacy@rcn.sh。

terminus 是一个独立的学生项目，与 NUS 没有关联。巴士时间来自 NUS 的校园巴士数据。
