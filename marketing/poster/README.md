# Campus poster

An A3 poster for noticeboards around campus: `poster.pdf` to print,
`poster.png` (2380 × 3368) for screens.

`poster.html` is the source, drawn at 1190 × 1684 CSS pixels with the
website's own fonts (from `apps/web/public/assets/fonts`) and the shuttles'
livery colours. `qr.svg` opens https://terminus.run.

To change it, edit `poster.html` and open it in Chrome to check, then:

- **PDF:** Print, Save as PDF, paper size A3, margins None, background
  graphics on, scale to fit the page.
- **PNG:** in DevTools, set the device to 1190 × 1684 at a pixel ratio
  of 2, then Capture screenshot.

Scan the QR code with a phone before printing.
